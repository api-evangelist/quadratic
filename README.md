Quadratic is an AI-native infinite spreadsheet that combines Python, SQL, JavaScript, formulas, and AI agents on a single canvas, with live connections to databases like PostgreSQL, MySQL, BigQuery, and Snowflake. Its token-authenticated Developer (Spreadsheet) API and remote MCP server let agents and applications programmatically read and write cells, run code and SQL, build tables, and orchestrate spreadsheets.

**Areas:** Company · Artificial Intelligence · Spreadsheets · Analytics · Data · Developer Tools · MCP · Productivity

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Quadratic: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
